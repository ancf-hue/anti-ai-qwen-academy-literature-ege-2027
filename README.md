## 🎯 О проекте

Одностраничный HTML-тренажёр, составленный по **проекту демоверсии, спецификации и кодификатора ЕГЭ-2027 по литературе**. Работает полностью офлайн — достаточно открыть `index.html` в браузере.

Никаких серверов, аккаунтов, рекламы и аналитики. Все ответы и прогресс хранятся только в памяти вкладки.

## ✨ Возможности

- 📝 **11 заданий** по структуре ЕГЭ-2027:
  - 6 заданий с кратким ответом (1–3, 6–8);
  - 4 задания с развёрнутым ответом ограниченного объёма (4, 5, 9, 10);
  - 1 сочинение (11.1–11.5, ≥ 200 слов).
- 🧮 **48 первичных баллов** — веса заданий соответствуют спецификации.
- ⏱ **Таймер экзамена** с пресетами: 235 мин / 60 мин / 30 мин, предупреждение и сигнал об окончании.
- ✅ **Автопроверка** кратких ответов и учебная подсказка для развёрнутых (по критериям ФИПИ).
- 📋 **Чек-лист подготовки** — 20 пунктов по произведениям кодификатора.
- 🗓 **25-дневный план** повторения всех тем.
- 🌐 **RU / EN интерфейс** — переключение одним кликом.
- 📱 **Адаптивный дизайн** — десктоп, планшет, телефон.
- 🔒 **100% офлайн**, без рекламы и трекеров.
